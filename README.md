# BarberBot

[Минутное видео](docs/demo/barberbot.mp4) · [Кейс со снимками экранов](docs/case-study.md)

Демонстрационный Telegram-бот для записи в барбершоп. Клиент выбирает услугу и время, оставляет контакты и получает подтверждение. Администратор получает данные записи в личном чате.

## Возможности

- Запись к Сергею, Максиму, Алексею или любому свободному мастеру. В варианте «Любой мастер» ближайшие старты показаны вместе с именами мастеров.
- Календарь на семь дней, включая сегодня. Барбершоп открыт ежедневно с 10:00 до 20:00 по Москве. Начало визита выбирают с шагом 30 минут, а запись должна закончиться до закрытия или ровно в 20:00.
- Клиент видит старты, для которых свободен весь интервал услуги. Например, запись на 40 минут с 13:00 убирает старт в 13:30 у того же мастера.
- Клиент может отменить или перенести визит до его начала. При переносе прежнее время освобождается после успешного бронирования нового. Администратор видит оба времени в уведомлении.
- Один клиент не может забронировать пересекающееся время у разных мастеров. «Мои записи» обновляет одну карточку со страницами для нескольких визитов.
- Уведомления о записи, отмене и переносе сохраняются в SQLite. При временном сбое Telegram бот повторяет доставку. Предыдущее напоминание обновляется после переноса или отмены.
- Администратор видит сегодняшние записи, добавляет услуги с длительностью и управляет получасовыми блокировками по мастерам. При отмене администратором уведомление получает клиент.
- Напоминание за 24 часа для записей, сделанных как минимум за сутки, содержит кнопки «Подтвердить визит» и «Перенести запись». После переноса отсчёт и статус подтверждения относятся к новому времени. Администратор видит статус в разделе «Записи по датам».

## Записи и графики в админ-панели

- **Графики мастеров**. Выберите мастера и день недели. Нажмите «Выходной» или введите смену с дополнительными перерывами, например `10:00–19:00 | 17:00–17:30`. Обед с 14:00 до 15:00 по Москве действует ежедневно для всех мастеров. Новые визиты не могут пересекать обед. Существующие визиты сохраняются.
- **Записи по датам**. Посмотрите визиты на сегодня или на любой из шести следующих дней.
- **Управление мастерами**. Добавление и удаление требуют подтверждения. Удалённый мастер пропадает из новой записи. Уже оформленные визиты сохраняются, и мастер снова становится доступен при добавлении с тем же именем.
- **Записать клиента**. Выберите услугу, мастера, дату и время, затем введите имя и телефон. Если у клиента привязан этот номер, визит появится в его «Моих записях» и бот сможет прислать уведомления. Клиент может привязать собственный номер через `/phone`, даже если визит уже оформлен.

## Стек

Python 3.11+, aiogram 3, SQLAlchemy 2.0 async, aiosqlite, APScheduler, python-dotenv, tzdata, pytest и pytest-asyncio.

## Запуск

1. Напишите **@BotFather** в Telegram, отправьте `/newbot` и следуйте инструкциям. Сохраните полученный токен.
2. Узнайте свой числовой Telegram ID, например через команду `/start` в **@userinfobot**.
3. В корне проекта выполните команды для PowerShell.

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   Copy-Item .env.example .env
   ```

4. В `.env` укажите `BOT_TOKEN` и `ADMIN_ID`. При необходимости измените `DATABASE_PATH`. По умолчанию база появится в корне проекта.
5. Запустите бота. Администратору нужно один раз отправить ему `/start`, чтобы бот мог присылать уведомления.

   ```powershell
   .\.venv\Scripts\python.exe -m app.main
   ```

На macOS и Linux используйте `cp .env.example .env` и интерпретатор `.venv/bin/python`.

При запуске бот обновит имеющуюся базу автоматически. В базе с тремя мастерами назначения и длительности сохранятся. При обновлении самой ранней базы с одним мастером записи и блокировки будут назначены Сергею, а длительность визитов сохранится равной 60 минутам.

## Команды

- `/start` открывает меню с кнопками «Записаться» и «Мои записи».
- `/phone` позволяет поделиться своим номером для привязки телефонных записей.
- `/admin` и кнопка «Админ-панель» в главном меню открывают панель для пользователя с ID из `ADMIN_ID`. При отмене визита администратор может добавить причину в уведомление клиенту.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты используют отдельную временную базу. В Telegram запишите 40-минутную услугу у Сергея на 13:00. Проверьте, что старт в 13:30 исчез у Сергея и доступен у другого мастера. Отмените визит через «Мои записи» и проверьте уведомление администратора и доступность времени. При отдельной отмене из админ-панели проверьте уведомление клиента.

## Структура

- `app/main.py` запускает бота и планировщик.
- `app/config.py` читает настройки из окружения.
- `app/db/` содержит модели и подключение к SQLite.
- `app/handlers/` и `app/keyboards/` описывают диалоги и кнопки.
- `app/services/` управляет расписанием, записями и уведомлениями.
- `app/utils/` проверяет номер телефона.
- `tests/` содержит тесты, а `docs/case-study.md` описывает демонстрационный кейс.

## Возможности платной версии

Исключения в графике на отдельные даты, лист ожидания, отчёты по загрузке и подключение CRM.

Бот рассчитан на один запущенный экземпляр. Незавершённый диалог записи хранится в памяти процесса. Подтверждённые записи и отметки о напоминаниях сохраняются в SQLite.
